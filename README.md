# 🎬 Ad Breakdown Portfolio

### Great ads aren't luck. Here's how they work.

**50 viral campaigns. Taken apart, one decision at a time.**

👉 **[Explore the reports](https://yashyadav1997.github.io/ad-breakdown-portfolio/Ad%20Breakdown.html)**

Why did a cranberry juice TikTok take off? How did KFC turn running out of chicken into an apology people loved? And what went wrong for Pepsi? Every report digs past the applause to the strategy underneath.

## 🔍 Inside every teardown
- **The problem** – what the brand needed to fix
- **The people** – audience and the insight that moved them
- **The creative** – story, sound, colour and semiotics
- **The strategy** – proposition, STP and AIDA
- **The rivals** – how competitors compare
- **The scoreboard** – results and KPIs
- **The verdict** – what worked, what didn't, and what I'd do next

## 🎨 Dressed for the brand
Each report wears its brand's own mood, with matching colours and look-alike fonts. Coca-Cola goes red and scripted. Liquid Death goes full heavy metal.

## 🛠️ Structure
- `Ad Breakdown.html` – home page
- `reports/*.html` – one report per campaign (data is an inline JSON block)
- `assets/` – shared `style.css`, `render.js` and `themes.js` (per-brand colours and Google Fonts stand-ins)

No build step. Open `Ad Breakdown.html` in a browser, or view it on GitHub Pages.

## ➕ Adding a report
Copy any file in `reports/`, edit the JSON block, and add a link in `Ad Breakdown.html`. Map the new file name to a brand theme in `assets/themes.js`.

## 📌 Data note
Independent analysis. Brands and campaigns belong to their owners. Results are publicly reported figures and should be verified against the original source before commercial use.
